# CodeProfiles

Repository for information on my code profiles.

## Approach

Notes on code approach:
- use `miniconda` to manage environments (`environments`)
    - separate environments for different topics, and separate one for Jupyter
    - initialize environments with `conda create --file env_xx.yaml`
- repository for each project, with standard repository management files (`repo_files`)

## Contents

- environments: definition files for environments
- repo_files: template repository files
    - add to each project repository: README.md, .gitignore, LICENSE, requirements.txt
